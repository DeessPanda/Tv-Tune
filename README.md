# Tv-Tune

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

**Tv-Tune** is a lightweight, ad-free YouTube Music client engineered specifically for Android TV and Google TV devices. Built for seamless 100% remote D-pad navigation, it features Jellyfin-style synchronized scrolling lyrics with lookahead, infinite auto-queue playback, smart listening history and recommendations, intelligent audio volume normalization (-13.0 LUFS), easy TV pairing/login, and lean memory optimizations designed to run smoothly on low-RAM TV streaming boxes.
